# Android 夜间使用限制

## 当前目标

- 每天 22:30 至次日 06:30 限制普通手机使用；时间段可配置。
- 到结束时间自动恢复正常使用。
- 限制期间保留来电接听、电话声音和闹钟响铃能力。
- 这替代了最初仅提供通知提醒的 Android MVP 方向。
- 不读取、不收集、不保存 Android 或 Windows 的系统锁屏密码。

## 已确认的目标设备与交互

- 荣耀 Magic 8，MagicOS 10，Android 16（用户于 2026-10-19 提供）。
- 限制时段内不需要临时使用手机，不提供 App 内解锁、延后、跳过或密码解除。
- 允许电话、闹钟及系统紧急呼叫；不修改系统锁屏密码，也不要求用户提供密码。
- 启用前提供自动结束的 60 秒兼容性试锁，用户亲自验证来电和闹钟后再确认启用；不把试锁当作正式限制期间的解除入口。

## 实现边界

- 普通系统锁屏仍允许用户使用系统密码解锁，不能单独实现整个夜间时段的使用限制。
- 普通 Android 应用无法保证完全不可绕过。实际拦截需结合手机型号、系统版本与用户主动授予的系统能力设计；不能把提醒页面当作不可解锁的系统锁屏。
- 必须在目标手机上验证来电、接听界面和闹钟响铃；尚未通过真机验证，不承诺完整兼容。
- 首版使用无障碍服务覆盖普通应用，按实际安装的电话／闹钟组件包名整体放行，不伪装成系统锁屏。
- 系统停止服务、重启、改时间及机主卸载等仍可能解除限制；不承诺不可绕过。
- 本阶段没有启用手机限制、授予系统权限或改变既有 Windows 关机设置。

## 电脑端候选方向

用户提出电脑也可能采用相同时段的限制方式。普通 Windows 锁屏可以保持后台任务运行，但知道系统 PIN／密码仍可解锁。定时使用限制与普通锁屏需分别设计；现有 Windows 版本仍采用已实现的定时关机流程，尚未切换为新方案。
