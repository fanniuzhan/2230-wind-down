# 收工助手 · Android 手机 App

版本：0.1.2 测试版。桌面名称：收工助手。安装文件：`收工助手-0.1.2-安卓测试版.apk`。本版增强熄屏／解锁后的遮罩恢复，并保留 0.1.1 的系统时钟备用入口。

这是可安装、独立运行的原生安卓应用。手机使用时无需电脑、模拟器、账号或网络。界面采用暖纸色、橄榄绿、月相与细线山景。

## 安装到荣耀 Magic 8

1. 用 USB 文件传输或你常用的文件传输工具，把 APK 传到手机“下载”文件夹；只需传 APK，其余文件用于说明和预览。
2. 在手机“文件管理”中打开 APK，按系统提示允许当前文件来源安装，完成后打开“收工助手”。它是测试版侧载应用，尚未上架应用商店。
3. 首次安装计划默认关闭，默认时段为每天 22:30–次日 06:30。核对时间和星期，修改后点“保存计划”。覆盖安装会保留你已有的时段设置。
4. 展开“本机检查”，依次完成 **01 开启服务 → 02 试试电话与闹钟 → 03 确认结果**。第二步准备页可打开系统闹钟；先设好闹钟、准备另一部手机拨入，再开始 60 秒试锁。
5. 亲自确认来电可接听、闹钟可响铃和关闭，再勾选确认并开启夜间计划。处于所设时段时，开启后会立即限制普通应用。

已有 0.1.0／0.1.1 时直接打开新版 APK 覆盖安装，无需卸载，原有时段和设置会保留。如果“打开系统闹钟”仍失败，可先从手机桌面打开“时钟”设置闹钟，再返回 App；仍须亲自验证夜间页面的闹钟入口。

**试锁与整晚计划不同**：60 秒试锁熄屏后仍继续计时，一分钟后恢复使用是正常行为。要在 22:30–次日 06:30 持续限制，需完成兼容性确认，再开启“夜间计划”。正式限制时段内，电源键熄屏再解锁后应恢复遮罩；若没有恢复，请查看服务是否仍连接及当前是否在已保存时段内。

若无障碍开关显示“受限设置控制”，请到“设置 → 应用 → 应用管理 → 收工助手”，在应用信息页查找“允许受限设置”（可能位于右上角菜单），按系统提示确认后再返回授权。App 不会自动解除此系统保护。

安装 APK 不会自动授权服务或启用计划。夜间到结束时间自动恢复，App 内没有临时解除入口。普通应用无法实现完全不可绕过的系统锁定，系统停用、强行停止、卸载或后台管理仍可能影响限制。
