# Custom Wind-down · Android 夜间使用限制

原生 Java Android 应用，目标手机为 **荣耀 Magic 8 / MagicOS 10 / Android 16**。默认每天 **22:30 至次日 06:30** 覆盖普通应用，到时自动恢复；时间和执行星期可在限制时段外修改。首次安装默认关闭。

这是自律限制工具，使用用户主动开启的无障碍服务和覆盖窗口，并非不可解除的 Android 系统锁。夜间没有 App 内临时解除、延后、跳过或 PIN 入口；机主仍能通过系统能力停用、强行停止或卸载应用。手机重启、系统后台管理也可能影响服务。

## 安装和首次启用

1. 将构建生成的 `artifacts/CustomWindDown-android-0.1.0-debug.apk` 传到手机，手动安装。无需电脑端运行，也不连接 Windows 程序。
2. 打开“收工助手”，核对时间、星期；星期表示开始限制的那一天，例如周一包含周二凌晨。
3. 展开首页的 **本机检查**，按 **01 开启服务** 阅读用途说明，自行到系统无障碍设置中启用“收工助手 · 夜间使用限制”。侧载应用若被 Android 限制敏感设置，请按系统提示自行决定是否允许；程序不会自动授予权限。
4. 在 **02 试试电话与闹钟** 点击 **准备 60 秒试锁**。准备页提供“打开系统闹钟”，先设置约一分钟后响铃，返回后准备另一部手机拨入，再点“开始试锁”。实际检查来电能接听、闹钟能响铃和关闭，以及返回普通应用后遮罩恢复。试锁自动结束，不启用正式计划。
5. 仅在两项实测通过后，在 **03 确认结果** 勾选兼容性确认，再开启正式计划并确认。若当前处于设置的时段，会立即开始限制。重新试锁会关闭原有正式计划，试锁通过后需重新启用；取消兼容性确认也会关闭计划。
6. 根据 MagicOS 当前版本的实际设置检查后台运行、电池管理与服务保活；这些设置不会被程序自动修改。测试锁屏后重新解锁、重启后服务连接情况。

夜间覆盖页面仅提供电话、闹钟和紧急拨号入口。紧急拨号使用公开的拨号 Intent，打开预填 112、可修改的拨号盘，不会自动呼叫；Android 锁屏自带的紧急呼叫功能保持原样。不要为测试拨打紧急号码。电话和闹钟是按应用包名整体放行，因此这些系统应用的其他页面也可能使用。

首页采用“月夜手记”样式：暖纸底色、橄榄绿、衬线时间、月相与细线山景，集中显示启用状态和休息时间。本机检查采用三张一致的步骤卡，每张都有编号、标题、说明和操作；闹钟准备收进第二步的准备页，不再与授权、试锁混作同层按钮。时间与星期改好后点击“保存计划”。夜间页面采用统一深色样式；大字体下时间区域改为纵向排列，内容可滚动。

**尚未通过荣耀真机验收。** 识别到电话和闹钟组件不等于通话、响铃与接听界面都兼容；若试锁失败，不要确认启用。未来系统升级、换电话或闹钟应用后，应在白天重新试锁。正常日常使用前还需验证完整夜间结束流程。

## 在电脑上测试

本机准备完成后，双击仓库根目录的 **`测试安卓.cmd`** 即可打开 Android 16 模拟器并安装／更新同一个 APK。无需每次下载、传文件或连接手机。初次 Android 开机可能较慢；以后可重复打开此入口。夜间遮罩只影响虚拟手机界面，不会锁住电脑。

在其他 Windows 电脑首次准备时，先完成下方构建工具和 APK 构建，再执行一次：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-android-emulator.ps1 -Setup
```

首次需下载约 1.3 GB 的官方模拟器与 AOSP Android 16 x86_64 镜像，缓存盘至少留 8 GB。默认放在 `%TEMP%\CustomWindDown-android-emulator`，避免占用源码所在盘；清理系统临时目录后需重新准备。可用 `scripts/setup-android-emulator.ps1 -CacheRoot <自选绝对路径>` 另选位置。下载包校验值来自 Google 官方仓库，脚本不会修改 Windows 虚拟化功能；需要电脑已启用 WHPX 加速。

专用虚拟设备名为 `CustomWindDown_API36`，固定连接 `emulator-5580`。启动器只安装和打开 App，不自动授予无障碍权限、不自动开启夜间计划。像手机一样，可以在其中开启服务、体验 60 秒试锁或设置几分钟的计划。

另有显式授权的自动冒烟检查（需要 Python 3），只接受上述测试 AVD：

```powershell
python .\scripts\test-android-emulator.py --enable-test-accessibility --reset-test-app
```

追加 `--test-alarm` 可在专用 AVD 中预设一次真实系统闹钟，检查试锁期间仅显示通知的闹铃是否也能撤下遮罩，再按测试标签解除该次闹钟。
此选项会重启专用模拟器内的 AOSP Clock 并允许它显示通知；不会改闹铃音量或真实手机。追加 `--test-layout` 可检查 360dp 窄屏、150% 字体下的时间选择和展开检查，随后恢复模拟器显示设置。

这两个参数表示同意**只在专用模拟器**内开启本应用无障碍服务，并重置本应用测试数据。脚本保留其他无障碍服务，模拟来电不产生真实通话，截图保存在 `artifacts/android-emulator`。不会连接真实手机、修改 Windows 收工设置或启用正式夜间计划。

Android 的 `uiautomator dump` 会在读取控件树时短暂暂停其他无障碍服务，脚本在点按前等待服务恢复。试锁中的拦截、来电和闹铃断言直接使用 `dumpsys`，不会在这些检查期间附加 UiAutomation。

模拟器可验证通用 Android 的界面和服务交互。MagicOS 的后台管理、电话／闹钟具体组件和实际铃声输出仍需最后在荣耀手机上实测；无需每次开发都到手机上重复测试。

## 行为与边界

- 使用手机本地时间，开始时刻包含在内，结束时刻不包含。跨午夜按前一天的星期计算。
- 服务运行期间直接按当前时间判断。夜间重启或恢复服务会重新进入当前限制时段，已过结束时间则解除；不主动唤醒手机。
- 系统时钟或时区改变会改变当前限制区间；本版没有防改时间机制。
- 每次窗口变化和周期计时均检查状态；未限制时最多每 60 秒复查，限制时每秒刷新。后台边界闹钟使用非精确调度，不申请精确闹钟权限；不保证绝对准点。
- Android 系统锁屏仍由系统管理，解锁后若在限制时段会重新覆盖。无需提供、更改或保存系统锁屏密码。
- 遇到已识别电话、闹钟界面、来电响铃或系统报告的闹铃播放状态，撤下遮罩；闹铃停止后恢复限制。这也处理解锁状态下只显示通知的闹钟。不会设置勿扰、音量、静音或停止闹铃；若系统原本静音，本应用不会改成有声。
- 没有识别到电话或闹钟组件，或服务出现异常时，撤下遮罩并记录错误，避免妨碍来电。
- 服务被系统停止时无法拦截，主界面显示未连接；不是设备所有者模式、系统应用或 kiosk。

## 数据与权限

计划、首次说明确认及兼容性试锁状态仅保存在应用私有 `SharedPreferences` 中，不备份到云端。清除应用数据或卸载会清除计划。无账号、服务器、广告、遥测及网络权限。

普通清单权限只有 `RECEIVE_BOOT_COMPLETED`，用于重启后重算边界。无障碍服务由 Android 的 `BIND_ACCESSIBILITY_SERVICE` 保护，必须由用户手动授权；系统会授予窗口读取能力，代码仅检查顶层窗口所属包名，不读取屏幕文字、描述、子节点或输入，不录制按键。另使用公开的匿名音频播放元数据，仅判断是否有 `USAGE_ALARM` 播放，不接触声音内容、不录音。无需设备管理员、联系人、录音、通知读取、电话状态、悬浮窗或精确闹钟权限。

## 构建

可使用 Android Studio 打开本目录，安装 JDK 17、Android SDK Platform 36、Build Tools 36.0.0，使用 Gradle 8.13 / Android Gradle Plugin 8.13.2。没有第三方应用运行时依赖，最低 Android 8.0（API 26），目标 API 36；低版本厂商兼容性未验收。

Windows 项目提供本地工具链脚本，不修改系统环境变量。首次下载需要联网，并接受相应构建工具的许可证：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\bootstrap-android.ps1 -AcceptSdkLicenses
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-android.ps1
```

在仓库根目录执行。工具、缓存和 APK 位于被 Git 忽略的 `artifacts` 中；不会安装到手机、授予权限或自动开启计划。脚本运行核心回归程序、APK 构建与 Android lint。也可使用已安装的 Gradle：

```powershell
.\android\gradlew.bat -p android :core:regressionTest :app:assembleDebug :app:lintDebug
```

仓库自带 Gradle Wrapper，分发包使用官方 SHA256 校验。脚本额外核实 APK 签名，并输出同名 `.sha256` 文件与中文说明。

提供的是 **debug 签名测试 APK**，不是商店正式发行版；新机器生成的 debug 密钥不同，可能无法覆盖旧版本。不要将私有签名密钥提交仓库。源码许可证暂未选择。

## 结构

- `core`：纯 Java 跨午夜日程及放行策略，无 Android 依赖。
- `app`：中文界面、设置保存、组件发现、无障碍服务及边界调度。
- `VALIDATION.md`：实际验证结果和真机验收清单。

现有 Windows 版继续采用定时正常关机，本次没有切换或修改其设置。
