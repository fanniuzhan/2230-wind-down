# Custom Wind-down · 收工助手

**到点收工，给休息留一点时间。** 一个仅作用于本机的 Windows 桌面助手。

首版默认每天 **22:30** 收工，支持自定义时间、执行星期、提前提醒、延后和跳过。首次运行 **不会自动启用关机计划**。

## 使用便携包

1. 将 `CustomWindDown-0.1.0-win-x64.zip` 解压到一个固定位置。
2. 打开其中的 `CustomWindDown.exe`，无需另装 .NET，支持 Windows 10/11 x64。
3. 先点击 **预览提醒 · 不会关机**，体验提醒界面。预览中的延后和跳过不改变真实计划。
4. 设置时间（`HH:mm`）和星期，核对界面显示的电脑名称。
5. 勾选 **在这台电脑启用定时关机**，点击 **保存计划**，确认本机后才会启用。

请只在需要定时关机的笔记本上启用。助手不连接、不控制工位电脑，也没有远程关机功能。

## 日常操作

- 提前 **10 分钟**弹出提醒；点击 **延后 15 分钟**可多次延后，只影响本次。
- **跳过本次**会跳到下一个执行日，不修改每周计划。
- 关闭提醒窗口不会取消关机；取消本次请点“跳过本次”。
- 关闭主窗口后仍在系统托盘运行。双击托盘图标打开窗口，右键可跳过或 **彻底退出（停止计时）**；主窗口底部也可彻底退出。
- **随 Windows 登录启动**默认关闭，开启后登录时在托盘启动。移动便携程序后，应关闭再开启该选项以更新路径；不要直接从 ZIP 内运行。
- 时间和星期修改后需要保存；取消勾选启用选项会立即停止当前计划。
- 最近动态只记录最后一次操作或关机请求，不会把“发出请求”当作“已成功关机”。

## 关机与错过计划的规则

- 到时调用 Windows **正常关机**，不会强制结束应用。请提前保存文件；未保存工作可能阻止关机。
- 同一次计划只请求一次，失败或被应用阻止后 **不会自动重试**。
- 退出程序、睡眠或关机期间错过的计划直接跳过；启动或唤醒不会补关机，不会唤醒电脑。
- 程序检测到超过 60 秒的计时中断，会跳过已到期的计划；向后调整时钟也不会重新执行已消费的计划。
- 使用电脑本地时间。夏令时中不存在的时刻跳过，当天重复时刻仅采用较晚的一次。
- 切换系统时区时跳过当前待执行计划，后续按新时区计算，避免时间突然提前。
- 首版依赖用户已登录且程序运行；不是 Windows 后台服务。

## 设置与隐私

设置在 `%LocalAppData%\CustomWindDown\settings.json`，包括计划、当前延后／跳过状态和最近动态。采用原子替换保存，上一版为 `settings.json.previous`；便携包移动不会丢失设置。

设置无法读取或绑定的电脑名称不一致时，计划恢复为禁用。保存失败时停止当前进程内的计划，不发起关机；排除文件权限／磁盘问题后重新保存。若无法写盘，旧的已保存设置仍可能在下次启动时载入，请检查状态。

登录启动使用当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\CustomWindDown`，无需管理员权限。没有账号、云端同步、遥测或网络通信。

## 开发

需要 Windows 和 **.NET SDK 8**。WPF 与核心逻辑仅使用 .NET 自带组件，不引入第三方应用依赖。

```powershell
dotnet build CustomWindDown.sln -c Release
dotnet run --project tests/CustomWindDown.Tests -c Release
dotnet run --project src/CustomWindDown.App
```

测试是独立的命令行回归程序，返回非零退出码表示失败；不是 `dotnet test` 项目。测试只调用模拟关机接口，**绝不执行真实关机**。生成的测试数据保留在已忽略的 `artifacts/test-data` 下。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish.ps1
```

发布脚本生成自包含单文件 EXE 及便携 ZIP，输出到已忽略的 `artifacts`。首次发布需从 NuGet 获取 Microsoft Windows x64 运行时包。无需管理员权限；单文件应用会在首次运行时解包原生组件到 .NET 管理的临时位置。

### 结构

- `src/CustomWindDown.Core`：调度状态机、设置存储、关机接口与执行协调。
- `src/CustomWindDown.App`：中文 WPF 界面、托盘、Windows 关机和登录启动。
- `tests/CustomWindDown.Tests`：时间、持久化、设备边界、失败路径及模拟关机验证。

## MVP 边界

手机端、远程控制、多设备同步、安装器、代码签名与自动更新暂未提供。便携 EXE 未签名，Windows 的提示取决于本机策略。未选择开源许可证；公开仓库本身不授予使用、修改和分发许可。
